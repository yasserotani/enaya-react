# Clinic Management System – Admin Dashboard

This project is a React-based admin dashboard for managing a Clinic Management System (CMS).
It connects to a Laravel REST API to handle clinic operations such as users, appointments, and queue monitoring.

## Features (MVP)

- Authentication (Login / Logout)
- User Management (Admin, Doctor, Patient)
- Appointments Management
- Queue Monitoring
- Role-based access control

## Tech Stack

- React (Vite)
- Axios (API communication)
- React Router (navigation)
- Laravel API (backend)

## Installation

```bash
npm install
npm run dev
```
